# Toddler's Town Day Care and After Care website

A simple static website. No build step needed.

## Put it on GitHub Pages
1. Create a new repository on GitHub (for example `toddlers-town`).
2. Upload everything from this folder (drag and drop into the repo, then commit).
3. Go to **Settings > Pages**, set **Source** to `Deploy from a branch`, choose `main` and `/ (root)`, then Save.
4. After a minute your site is live at `https://YOUR-USERNAME.github.io/toddlers-town/`.
